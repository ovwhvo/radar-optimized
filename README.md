# 政策补贴雷达

用一句话描述你的经营问题，找到相关政策，再把申报条件与办理资料逐项整理清楚。免登录、纯前端、数据只存本浏览器的展示原型。

**在线试用：<https://ovwhvo.github.io/radar-optimized/>**

## 功能

- **自然语言检索**：输入"我们在龙岗做软件研发，想了解研发投入扶持"这类真实问题，本地词典引擎识别地区与政策主题，给出带匹配理由的候选清单；未覆盖地区会明确提示并保留全国适用政策。
- **条件核对**：对所选政策逐条初筛——结构化条件自动比对企业档案，专项条件引导你按官方口径补充自报（是/否/待确认 + 资料依据 + 所属期间），并用绿/红/黄/灰四色区分"初步满足 / 初步不符 / 待补信息 / 待核规则"。缺信息不会被判为不符合。
- **资料准备**：办理流程分步展示、材料清单逐项勾选、官方表格口径整理为可草稿字段，全部进度实时保存。
- **确定性问答助手**：围绕所选政策回答解释、材料、流程、填写口径类问题，回答附原文依据锚点（模拟模式，不构成官方结论）。
- **过程管理**：保存/恢复准备记录（含最多 20 个历史版本与版本对比）、冲突检测、导出 Markdown / JSON 备份。
- **官方可追溯**：每条政策、条件、材料都带官方来源链接；政策库附 13 份官方页面留存快照。
- **政策库**：10 条公开官方样本——全国税惠与资质制度（高新技术企业认定、科技型中小企业评价、小规模增值税减免、六税两费减免、研发费用加计扣除、小微企业所得税优惠）+ 深圳/龙岗地方专项（研发扶持、高企、科小、技术合同登记）。非全量政策库，数据核验日期见各条目。

## 隐私（核心设计，可核验）

| 承诺 | 实现 |
|---|---|
| 数据不出浏览器 | 企业资料、草稿、记录、历史版本、问题线索全部存于本应用的 localStorage；代码中没有任何上传路径 |
| 无账号、无同步 | 不注册、不登录、不提供云端同步；换设备即从零开始（请用导出备份） |
| 无第三方 | 不加载任何第三方脚本、字体、统计或广告代码；Content-Security-Policy 限定 `default-src 'self'` |
| 零外链请求 | 页面运行期间的全部网络请求仅指向本站（已用浏览器网络日志实测：外部请求 0 个）；只有你主动点击"官方原文"等链接才会离开本站 |
| 可携带、可销毁 | 任意记录可导出 Markdown/JSON；「工作设置 → 清除本浏览器全部数据」一键抹除，或直接清除浏览器站点数据 |

## 技术

- 纯静态站点（HTML/CSS/ES Modules），无构建框架；`build.py` 负责模块打包、CSS 合并、内容哈希与预压缩（零第三方依赖，Python 3.10+）
- 检索 / 核对 / 问答全部在浏览器内以确定性规则实现（`src/local-api.js`），健康检查与来源列表为随包静态数据
- 核对结果带 SHA-256 输入指纹，与本地存储层交叉校验，防止"旧分析配新事实"
- 并发安全：Web Locks + 版本前置条件（If-Match 语义），多标签页不会静默互相覆盖
- 安全响应头按 `nginx.conf.example` 配置（CSP、HSTS、nosniff、Permissions-Policy 等）

## 本地运行

```bash
python build.py          # 产出 dist/（哈希文件名 + .gz 预压缩 + data 整树）
python serve.py 8090     # 纯静态预览 http://127.0.0.1:8090/
```

部署：把 `dist/` 放到任意静态托管（GitHub Pages、nginx、CDN）即可，无需任何后端。

## 测试

```bash
python serve.py 8090 &
# 等价性/回归套件：tests/api-equivalence.html（打开后应显示 ALL PASS）
# 端到端冒烟：dist 部署后访问 / 并提交一次搜索，应渲染候选卡片
```

- `tests/reference/` 保存着基线响应快照；套件对检索结果保序子集、核对逐字段、指纹逐位一致做断言
- 无头浏览器净流量日志验证过"外部请求 0 个"

## 目录

```
src/        源码（14 个 ES 模块 + 8 个样式表 + data 政策库与官方快照）
dist/       构建产物（可直接部署）
tests/      回归套件与基线快照
serve.py    本地静态服务器      build.py   构建脚本
nginx.conf.example  生产响应头/缓存/压缩参考配置
```

## 数据与免责

政策资料为公开渠道整理的样本快照，核验日期标注于各条目；本工具不提供官方结论，申报前请以官方原文与当期通知为准。演示模式下问答为确定性模拟（页面顶部有常驻提示）。
